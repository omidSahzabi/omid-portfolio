# Authorized Octocat model integration

The default character is an original procedural cat built from source in `src/lib/experience/mascotGeometry.ts` and `OriginalCatCharacter.tsx`. It requires no model file.

This folder is an optional integration point for a licensed rigged GLB. Obtain the model and permission for its intended use before enabling the override in `src/lib/portfolio.ts`. See the root README for the integration contract and brand references. Do not label a custom or third-party model an official GitHub asset.
